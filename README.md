# AI 双语翻译（AI Bilingual Translator）

一个面向 **Microsoft Edge / Google Chrome** 的 MV3 浏览器扩展：把英文网页、英文字幕、选中的英文单词/句子翻译成中文，并在原文下方以双语对照的方式展示。

- 清单版本：Manifest V3
- 当前版本：**2.1.0**
- 支持浏览器：Edge / Chrome 116 及以上（Windows 10、Windows 11 实测环境为 Edge 156 / Chrome 156）
- 安装方式：开发者模式 → 加载解压缩的扩展（**无需构建、无需命令行**）

---

## 1. 能做什么

### 1.1 网页翻译

| 能力 | 说明 |
| --- | --- |
| 四种显示模式 | **双语**（英文在上、中文在下，默认）、**仅中文**、**悬停显示**（鼠标移上去才出现译文，不改变页面排版）、**关闭**（恢复原始页面） |
| 智能识别正文 | 逐层下沉到最深的块级元素，只翻译正文段落、列表项、表格单元格、标题；跳过导航、按钮、输入框、代码块、广告位 |
| 不重复翻译 | 每个节点只翻译一次，动态加载的新内容才会重新进入队列 |
| 动态内容 | `MutationObserver` + 防抖，滚动加载、SPA 切换页面后自动补翻 |
| 懒加载 | `IntersectionObserver` 提前 400px 预取，`requestIdleCallback` 插入译文，避免长页面卡顿 |
| 打字稿保护 | URL、文件路径、命令行、`snake_case`、`camelCase`、十六进制、`#include` 等片段先替换为占位符，翻译后原样还原；行内 `<code>` 也会高亮保留 |
| 站点规则 | 每个域名可设为「自动翻译 / 每次询问 / 永不翻译」，选择会持久保存，刷新后依然生效 |
| 标题翻译 | 可开关，开启后标签页标题变成 `中文标题 | 原标题` |

### 1.2 译文样式

字号倍率、字重、行高、段间距、译文颜色（亮色/暗色各一套）、左侧竖线、行内代码保留，全部可在设置页实时预览。译文插入在原文下方，不破坏原有字体、图片、链接和交互。

### 1.3 字幕翻译

- 优先读取 YouTube 播放器自带的字幕轨道（人工字幕优先，其次英文，最后才用自动字幕）。
- 读取失败时回退到识别页面字幕面板的文字（可靠性更低，界面会明确提示）。
- 英文原文在上、中文在下，按时间轴同步；全屏可用；暂停/快进后自动重新对齐；切换视频会自动重新识别。
- 位置、字号、颜色、透明度、行距可调；可隐藏平台原生字幕避免重叠。
- 独立的字幕面板标签页：看整份字幕列表、手动切换轨道、批量翻译、复制双语文本、导出 SRT。
- **不承诺一定可用**：如果 YouTube 限制接口或返回空内容，扩展会明确显示「字幕不可用」并给出原因，**不会**无限重试，也**不会**编造字幕。DRM/付费内容不做任何绕过。

### 1.4 划词查询与生词本

选中英文 → 浮出卡片，显示原文、译文、词性、释义、例句，可朗读、复制、一键加入生词本。支持右键菜单「用 AI 双语翻译查询」和快捷键。生词本与查询历史可在弹窗、侧边栏、设置页三处查看、搜索、导出 JSON。

### 1.5 引擎

分两大类，可分别配置、可测试连通性：

| 类型 | 引擎 | 是否需要 Key |
| --- | --- | --- |
| 翻译 API | Google 翻译（免费公共接口） | 否 |
| 翻译 API | DeepL API（Free / Pro） | 是 |
| LLM API | OpenAI 兼容接口（可自定义 Base URL、模型、温度、max_tokens） | 是 |
| LLM API | 阿里云百炼 DashScope 兼容模式 | 是 |

专业术语可预置术语表（`Register → 寄存器`、`Memory Management → 内存管理`、`Kernel → 内核`、`Pointer → 指针`、`Assembly Language → 汇编语言`、`System Call → 系统调用`），支持「通用 / 技术 / 学术 / 自定义」四种翻译风格，并可导入导出 JSON。

### 1.6 请求与缓存

同一批文本一次请求、超时重试（指数退避 + 抖动）、相同文本去重、`IndexedDB` 缓存、并发限流、关闭页面时取消进行中的请求。

## 3. 快速开始

1. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）。
2. 打开左下角「开发人员模式」。
3. 点「加载解压缩的扩展」，选择本仓库根目录（含 `manifest.json` 的那一层）。
4. 打开任意英文网页，点工具栏图标 → 「翻译本页」。

详细步骤见 [docs/安装教程.md](docs/安装教程.md)，各项设置的含义见 [docs/配置教程.md](docs/配置教程.md)，引擎配置见 [docs/API配置教程.md](docs/API配置教程.md)。

## 4. 隐私与安全

- 所有外部 API 请求都由 **Service Worker** 发出。内容脚本不会直接访问任何第三方域名。
- API Key 默认存放在 `chrome.storage.session`，**关闭浏览器即清除**；只有在设置页显式打开「持久化保存密钥」并确认风险后才会写入 `chrome.storage.local`。密钥不会出现在 `settings` 对象里，也不会返回给页面。
- 不收集浏览记录，不上报统计，不加载远程代码；`host_permissions` 只包含实际会用到的域名，自定义接口通过可选权限（`optional_host_permissions`）在需要时单独申请。
- 翻译缓存保存在本机 IndexedDB，可在设置页一键清空。

> 说明：浏览器本地存储不是专业的密钥保管方案。任何能在你电脑上读取浏览器配置的人，都可能读到持久化的 Key。请优先使用「仅本会话」模式或权限受控的 Key。

## 5. 开发与测试

```bash
# 单元测试（Node 20+，无需安装依赖）
node --test

# 静态自检：清单引用、语法、权限、禁用写法
node tools/validate.js

# 端到端：真实浏览器加载扩展 + 本地夹具页断言（优先用 Edge）
node tools/e2e-smoke.mjs

# 端到端 + 真实 Google 翻译请求（会访问外网）
node tools/e2e-smoke.mjs --google

# 生成图标（需要 Python + Pillow，图标已随仓库提供）
python tools/generate_icons.py

# 打包 ZIP（输出到 dist/）
python tools/build_zip.py
```

实测结果见 [docs/测试报告.md](docs/测试报告.md)：单元测试 40/40 通过，静态自检通过，端到端 12 个步骤全部通过（含真实 Google 翻译）。

扩展本身**不需要**打包构建：修改源码后在扩展管理页点「重新加载」即可生效。

## 6. 已知限制

见 [docs/已知问题.md](docs/已知问题.md)。最常被问到的几条：

- Google 免费翻译接口并非官方稳定 API，可能限流或失效，正式使用建议配置 DeepL / OpenAI 兼容 / 百炼。
- YouTube 字幕接口可能被平台限制，此时只能回退到页面字幕识别，或直接显示「字幕不可用」。
- 自动语音识别（ASR）字幕不做的原因是成本与稳定性；扩展只读取平台已有的字幕轨道。
- 纯 Canvas / 图片里的文字、PDF 内置阅读器中的文字不在翻译范围内。
- 后台标签页里触发翻译时，懒加载会让段落先显示「翻译中…」，切回该标签页后继续完成（浏览器不给不可见页面派发可见性回调）。
