# 安装教程（Edge / Chrome）

> 本扩展是「解压缩加载」形式，不需要联网安装、不需要构建工具、不需要 Microsoft Store / Chrome 应用商店。
> 下载来源二选一：GitHub 仓库源码（推荐）或 `dist/ai-bilingual-translator-v2.1.0.zip` 解压后的目录。

---

## 一、准备工作

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11（macOS、Linux 同样可用，步骤一致） |
| 浏览器 | Microsoft Edge 116+ 或 Google Chrome 116+ |
| 磁盘 | 约 2 MB |

查看浏览器版本：

- Edge：地址栏输入 `edge://version/`，看「Microsoft Edge」一行。
- Chrome：地址栏输入 `chrome://version/`，看第一行。

如果版本低于 116，请先更新浏览器（设置 → 关于 Microsoft Edge / 关于 Chrome）。

---

## 二、获取扩展文件

### 方式 A：从 GitHub 克隆

```bash
git clone https://github.com/xiaochen-china/ai-bilingual-translator.git
```

### 方式 B：下载 ZIP 并解压

1. 打开仓库页面右侧的 **Releases**，或在本地 `dist/` 目录找到 `ai-bilingual-translator-v2.1.0.zip`。
2. 右键 → 全部解压到 **一个固定目录**，例如 `D:\Extensions\ai-bilingual-translator`。
3. 解压后确认该目录下**直接**能看到 `manifest.json`，而不是又多套了一层文件夹。

> ⚠️ 扩展运行期间不要删除或移动这个目录，否则浏览器下次启动会提示「扩展已损坏」。

---

## 三、在 Edge 中加载

1. 地址栏输入 `edge://extensions/` 回车。
2. 打开页面**左下角**的「开发人员模式」开关。
3. 点击「加载解压缩的扩展」。
4. 在弹出的选择框里选中**包含 `manifest.json` 的那一层目录**，点「选择文件夹」。
5. 列表中出现「AI 双语翻译 2.1.0」即安装成功。
6. 点浏览器右上角「扩展」图标（拼图形状），把「AI 双语翻译」右侧的「眼睛」图标点亮，把它固定到工具栏。

## 四、在 Chrome 中加载

步骤与 Edge 完全相同，只是入口变成 `chrome://extensions/`，按钮文字是「加载已解压的扩展程序」。

---

## 五、第一次使用

1. 打开一篇文章，例如 <https://developer.mozilla.org/en-US/docs/Web/JavaScript>。
2. 点工具栏上的扩展图标，弹出面板里点 **翻译本页**。
3. 几秒后，每段英文下面会出现中文译文。
4. 弹窗顶部可以在 **双语 / 仅中文 / 悬停 / 英文** 四种模式之间切换；**英文**模式会把页面恢复成原始状态。

常用快捷键（可在设置页查看，部分可修改）：

| 快捷键 | 作用 |
| --- | --- |
| `Alt+Shift+T` | 翻译当前页面 |
| `Alt+Shift+M` | 切换显示模式 |
| `Alt+Shift+D` | 查询选中文本 |

如果快捷键无反应，通常是和其它扩展冲突：打开 `edge://extensions/shortcuts` 重新分配。

---

## 六、加载时常见报错

| 现象 | 原因与处理 |
| --- | --- |
| 「清单文件缺失或不可读取」 | 选中的目录里没有 `manifest.json`。重新选择**包含 manifest.json 的那一层**。 |
| 「清单版本无效 / Manifest version 3 不被支持」 | 浏览器版本过低，请升级到 116 以上。 |
| 「无法加载扩展程序，因为其清单包含无效值」 | 文件在解压/复制过程中损坏。重新解压或重新克隆。 |
| 安装后点图标没有任何反应 | 到 `edge://extensions/` 查看该扩展是否被停用，或点「错误」查看具体报错。 |
| 翻译按钮一直转圈 | 多为网络问题，见 [配置教程](配置教程.md#七网络与失败排查)。 |

---

## 七、更新与卸载

- **更新**：用 Git 的话 `git pull`；用 ZIP 的话解压覆盖原目录。然后在 `edge://extensions/` 点该扩展卡片上的「重新加载」。
- **卸载**：`edge://extensions/` → 该扩展卡片 → 「删除」。设置、生词本、缓存会随扩展一起删除；如需保留生词本，先在设置页「生词本 → 导出」。
