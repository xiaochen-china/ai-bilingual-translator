```bash
node --test
```

结果：**40 个用例全部通过，0 失败，0 跳过**。

覆盖范围（`tests/`）：

| 测试文件 | 覆盖内容 |
| --- | --- |
| `tests/text.test.js` | `looksEnglishText` / `detectLanguageHint` 判定阈值；`splitSentences` 中英文断句；`protectText` + `restoreText` 对 URL、文件路径、命令行、函数调用、标识符、十六进制、预处理指令的占位符保护与还原；占位符被模型改写（`⟦0⟧` / `[0]` / `【0】` / `<<0>>`）时的容错；`applyGlossaryPre` 长词优先与词边界；`hashText` 稳定性；`maskKey` 不泄露密钥；`chunkByChars`、`normalizeWhitespace`、`deepMerge` |
| `tests/protocol.test.js` | 消息信封构造（`v/type/id/payload`）、成功与失败响应结构、`validateEnvelope` 对版本不符/缺 type/空 payload 的拒绝 |
| `tests/engines.test.js` | `packTexts` 分批与顺序保持；Google 免费端点单条/多条响应解析；OpenAI 兼容输出解析（围栏代码块、对象形式、行数组、长度不匹配返回 null）；DeepL 目标语言映射与密钥 `:fx` 自动切到 free 端点 |
| `tests/subtitle.test.js` | `parseJson3` 事件解析；`parseTimedTextXml` 属性解析（`start`/`dur`，含 HTML 实体解码）；`parseTimedTextBody` JSON/XML 自动识别；`buildSrt` 时间轴格式 |
| `tests/helpers.js` | 共享常量（占位符样例），非测试文件 |

测试期间发现并修复的两个真实缺陷：

1. `src/common/text.js` 的 `splitSentences` 原正则无法切分中文（中文句号后没有空格），导致长中文段落无法分批 → 改为 `/(?<=[。！？；;])|(?<=[.!?])\s+|\n{2,}/`。
2. `src/background/subtitle-bridge.js` 的 `parseTimedTextXml` 原正则把 `dur` 放在可选组里，导致永远捕获不到时长（`duration` 恒为 0）→ 改为先匹配 `<text ...>...</text>`，再分别从属性串取 `start` / `dur`。

## 5. 未验证 / 受限项

以下项目**没有**在本机自动化验证，属于「已知未验证」，请以手工验证为准：

| 项目 | 原因 |
| --- | --- |
| Chrome 156 自动化加载扩展 | Chrome 156 无头模式即使带 `--disable-features=DisableLoadExtensionCommandLineSwitch` 也会忽略 `--load-extension`（`chrome://version` 里命令行可见该参数，但扩展列表为空、扩展的 Service Worker 不出现）。Edge 156 正常。Chrome 手工「加载解压缩的扩展」不受此限制，但本次没有自动化证据 |
| YouTube / Bilibili 真实视频字幕 | 需要真实视频页面与可用的字幕轨道；脚本只验证了「字幕接口在无视频页时给出明确失败原因」这一条（步骤 3 的 `subtitleHonest`） |
| DeepL / OpenAI 兼容 / 百炼 真实翻译 | 需要用户自己的 API Key，未在测试中使用任何密钥 |
| 站点规则「自动翻译」在刷新后的持久化 | 逻辑由 `chrome.storage.local` 承载，单元与静态层面已覆盖，但缺少自动化浏览器断言 |
| 悬停模式、字体/颜色等样式项的视觉回归 | 样式只在真实页面肉眼可评估，未做像素级比对 |

## 6. 复现步骤

```bash
npm run icons      # 可选：重新生成图标
npm test           # 40 个单元测试
npm run validate   # 静态自检
npm run test:e2e   # 端到端（默认不联网翻译）
node tools/e2e-smoke.mjs --google   # 端到端 + 真实 Google 翻译
npm run build      # 生成 dist/ai-bilingual-translator-v2.1.0.zip
```

端到端脚本会自动挑选本机已安装的浏览器（优先 Edge），并打印每一步的 `ok` / `detail`；任一断言失败时退出码为 1。
