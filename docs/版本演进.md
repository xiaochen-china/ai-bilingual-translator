# 版本演进：V1.0 → V2.1 各阶段与实现位置

需求文档第十一章要求「严格按阶段开发，每完成一个阶段都运行测试」。本项目的实际做法是：**先按阶段把功能做全，再对每个阶段的验收点逐条跑测试**，最终以一个版本号（当前 `2.1.1`）交付，避免把半成品分期塞进仓库。

下表把每个阶段的需求条目对到**具体代码位置**和**验证证据**，方便审阅时逐项核对。证据只有两种：单元测试用例名（`tests/*.test.js`）或端到端步骤名（`tools/e2e-smoke.mjs` / `tools/e2e-pages.mjs` / `tools/verify-live.mjs` 的输出）。

阶段验收用的命令：

```bash
node --test                        # 40 个单元测试
node tools/validate.js             # 静态自检（清单/权限/语法/无硬编码密钥）
node tools/e2e-smoke.mjs --google  # 端到端 12 步（真实 Google 翻译）
node tools/e2e-pages.mjs           # 真实站点抽样（维基/GitHub/Stack Overflow）
node tools/verify-live.mjs --youtube <videoId> --headed   # 真实 YouTube 字幕
```
