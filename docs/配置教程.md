# 配置教程

设置页入口（任选其一）：

- 工具栏图标 → 弹窗底部「设置」；
- `edge://extensions/` → 「AI 双语翻译」→ 「扩展选项」；
- 右键扩展图标 → 「选项」。

设置页共 9 个分区：**翻译引擎、翻译行为、译文样式、网页翻译参数、划词翻译、视频双语字幕、生词本、缓存与数据、快捷键与说明**。
绝大多数选项**改完立即生效并自动保存**（底部不会出现「保存」按钮）；术语表、引擎参数、密钥需要用各自区域的按钮显式保存。

## 一、翻译引擎

### 1.1 怎么选

| 场景 | 建议 |
| --- | --- |
| 刚开始用，只想试试 | Google 免费翻译（默认，无需配置） |
| 日常英文文章、长句要通顺 | OpenAI 兼容接口 + `gpt-4o-mini` 一类小模型 |
| 尊重术语、专业文档 | 技术翻译 + 术语表 + LLM 引擎 |
| 已在用 DeepL | DeepL Free / Pro（对英译中质量稳定） |
| 国内网络、低延迟 | 阿里云百炼（DashScope 兼容模式） |

「要配置的引擎」下拉框只是**切换当前正在编辑哪一个引擎的参数**，不会改变默认引擎；默认引擎在下一节「翻译行为 → 默认引擎」里设置。

### 1.2 参数说明

- **Google 免费翻译**：`接口地址` 默认 `https://translate.googleapis.com/translate_a/single`，无需密钥。这是公共接口，**不是**官方承诺的对外开放 API，可能限流（表现为「请求过于频繁」）或随时变更。
- **DeepL**：`接口类型` 选 Free 或 Pro；Free 的密钥以 `:fx` 结尾，选错会得到 403。`语气（formality）` 对中英互译影响很小，保持「默认」即可。
- **OpenAI 兼容接口**：填 Base URL（如 `https://api.openai.com/v1`）、模型名、温度（翻译建议 0–0.3）、单次最大输出 tokens。任何兼容 `/chat/completions` 的服务都能用，包括自建代理。
- **阿里云百炼**：Base URL 已预填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，模型默认 `qwen-plus`。

### 1.3 保存、测试与清除

1. 在「API Key」输入框粘贴密钥（默认 `password` 类型，可点「显示」核对）。
2. 需要重启浏览器后仍然可用，才勾选「持久化保存密钥」，并阅读旁边的风险提示。
3. 点 **保存引擎配置**。
4. 点 **测试连接**：扩展会先静默保存当前参数，再用一句固定的英文探测，显示 `连接成功 · 1234ms · 返回"…"` 或具体错误。
5. **清除密钥** 会同时删除会话与持久化两份密钥（会二次确认）。

密钥状态徽标有三种：`未设置`、`已保存（本会话）`、`已保存（持久化）`。

> 自定义 Base URL（如自建代理）需要额外的主机权限。首次保存时浏览器会弹出权限申请，**必须同意**，否则该地址的请求会被拦截。

## 二、翻译行为

| 选项 | 作用 |
| --- | --- |
| 默认引擎 | 网页、字幕、划词（未单独指定时）都使用它 |
| 源语言 | 一般保持「自动检测」；明确知道是英文时选 English 可减少误判 |
| 目标语言 | 默认「简体中文」 |
| 翻译措辞 | 通用 / 技术 / 学术 / 自定义规则。LLM 引擎会按该风格改写提示词；非 LLM 引擎只影响术语替换 |
| 打开页面时自动翻译 | 全局开关，可被站点规则覆盖 |
| 自定义翻译规则 | 仅「自定义规则」模式生效，直接拼进给模型的指令里 |

### 术语表

- 表格三列：英文 → 中文（必填）、备注（可选）。
- **对所有引擎生效，但实现方式不同**：
  - Google / DeepL：翻译**前**把英文术语替换成对应中文，翻译后再由引擎「看到」中文，因此译文里一定出现你的中文词；
  - LLM 引擎：术语作为强约束写进提示词，由模型自然融入句子。
- 因此同一个术语在两类引擎下的句子流畅度会不同，这属于预期差异。
- **支持导入导出 JSON**：导出得到 `[{ "en": "Register", "zh": "寄存器", "note": "CPU 寄存器" }]`；导入按英文（不区分大小写）去重后合并。
- 新增行后记得点 **保存术语表**；整行留空等于删除该行。

### 站点规则

- 三种取值：`auto`（打开就翻译）、`ask`（页面顶部询问一次，可选「本网站不再询问」）、`never`（不自动翻译，仍可手动点「翻译本页」）。
- 在表格里直接改下拉框即保存；点「删」删除该站点规则。
- 也可以不在这里添加：页面顶部询问条上的「本网站不再询问」会自动写入一条 `never` 规则。

## 三、译文样式

| 选项 | 说明 |
| --- | --- |
| 字号倍数 | 0.7×–1.4×，译文相对原文的字号比例 |
| 字重 | 常规 / 中等 / 加粗 |
| 行高 | 1.2–2.2 |
| 与原文间距 | 译文与上一段原文之间的距离（px） |
| 与下段间距 | 译文与下一段内容之间的距离（px） |
| 浅色/深色主题颜色 | 系统切换深浅色时自动选用对应颜色 |
| 左侧竖线 | 给译文加一条竖线，视觉上更容易区分原文与译文 |
| 代码等宽标注 | 译文里的 URL、路径、标识符用等宽字体并加浅底色 |

右侧「预览」会即时反映这些设置。样式只作用于译文元素，不会改动页面原有字体、图片、链接和交互。

## 四、网页翻译参数

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 单页最多文本块 | 800 | 超长页面只翻译前 N 块，避免一次发几百个请求 |
| 最小可翻译长度 | 4 | 少于该长度的碎片（如单个词、符号）跳过 |
| 每批文本数 | 8 | 一次请求打包多少段 |
| 并发请求数 | 2 | 同时进行几个请求；调高更快但更容易被限流 |
| 视口懒加载 | 开 | 只翻译滚动到附近（提前 400px）的段落 |
| 跟随动态内容 | 开 | 无限滚动、单页应用切换后自动补翻 |
| 翻译页面标题 | 开 | 标签页标题显示为「中文 | 原文」 |
| 翻译缓存 | 开 | 相同文本命中缓存时不再请求 |

> 翻译长文时如果发现「翻到一半停了」，先把「单页最多文本块」调大，再考虑关闭懒加载。

## 五、划词翻译

| 选项 | 说明 |
| --- | --- |
| 启用 | 关闭后选中文字不再有任何反应 |
| 选中后自动弹出 | 关闭后需按 `Alt+Shift+D` 或右键菜单查询 |
| 最大查询长度 | 超过该长度的选区不查询，避免误选整篇文章 |
| 划词使用的引擎 | 留空表示跟随默认引擎；选 LLM 引擎才能拿到词性、释义、例句 |

卡片上的按钮：

- **＋ 生词本**：把当前词条存进生词本（重复词条不会重复添加）。
- **复制**：复制「原文 + 译文」。
- **朗读**：用浏览器内置语音合成朗读原文（能否朗读取决于系统是否装了英文语音）。
- **关闭**：关闭卡片；按 `Esc` 或在卡片外点击同样可以关闭。

用非 LLM 引擎（Google / DeepL）时，卡片会明确提示「该引擎不支持词性/释义/例句」，只给译文——这是**有意的诚实提示**，不是缺陷。

## 六、视频双语字幕

| 选项 | 说明 |
| --- | --- |
| 启用 | 打开视频页面时自动尝试显示双语字幕 |
| 显示原文 | 关掉则只显示中文 |
| 隐藏站点原生字幕 | 避免和扩展的字幕层重叠 |
| 字号倍数 | 0.6×–1.8× |
| 距底部（%） | 字幕层距播放器底部的百分比 |
| 最大宽度（%） | 字幕层最大宽度，防止长句横跨整个屏幕 |
| 原文 / 译文颜色 | 分别设置 |

使用流程：

1. 打开 YouTube 视频，确认视频本身**有字幕轨道**（CC 按钮可用）。
2. 点弹窗里的「字幕」开关，或直接把鼠标移到播放器上，等字幕层出现。
3. 想调整轨道或看完整字幕：弹窗 → 「字幕面板」，会打开一个独立标签页，可切换轨道、批量翻译、复制双语字幕、导出 SRT。

行为边界（请务必了解）：

- 只读取平台上**已经存在**的字幕，不做语音识别。
- YouTube 若限制字幕接口，扩展会回退到识别页面上的字幕文字；仍然失败则显示「字幕不可用」及原因，**不会**反复重试、**不会**生成假字幕。
- 直播、DRM 视频、付费课程不做任何绕过。
- 全屏、暂停、快进、切换视频都会重新对齐时间轴。

## 七、生词本

- 数据来源：划词卡片的「＋ 生词本」。
- 设置页里可搜索、删除单条、清空全部、导出/导入 JSON。
- 「侧边栏打开」会在浏览器侧边栏打开学习面板，同一份数据分「生词本 / 查询历史」两个标签页。
- 生词本保存在本机，随扩展卸载一起删除，**请定期导出备份**。

---

## 八、缓存与数据

- `已缓存 N 条翻译（IndexedDB）` 是当前缓存条数；点击「刷新统计」可重读。
- 「清空翻译缓存」只删译文缓存，不影响设置和生词本。
- 「清除全部本地数据」会重置设置、删除全部密钥、清空生词本与查询历史，**不可恢复**。

## 九、显示模式与快捷键

| 模式 | 效果 |
| --- | --- |
| 双语 | 原文在上，中文在下（默认） |
| 仅中文 | 隐藏原文，只留译文 |
| 悬停 | 译文默认隐藏，鼠标悬停在该段时浮现气泡，不改变页面高度 |
| 英文 | 移除所有译文，恢复原始页面 |

快捷键：`Alt+Shift+T` 翻译当前页、`Alt+Shift+M` 循环切换模式、`Alt+Shift+D` 查询选中文字。
可在 `edge://extensions/shortcuts` 中修改或排查冲突。

## 十、网络与失败排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `请求超时` | 网络不通、接口被墙、代理未生效 | 换引擎（如百炼 / 自建代理），或在系统层配置代理 |
| `HTTP 429 / 请求过于频繁` | 免费接口限流 | 把并发数调成 1、调大每批文本数、或换引擎 |
| `HTTP 401 / 403` | 密钥错误、DeepL 选错 Free/Pro、Key 无权限 | 重新粘贴密钥，核对接口类型，点「测试连接」 |
| `未配置 API Key` | 用了需要密钥的引擎但没保存 Key | 见 [API 配置教程](API配置教程.md) |
| 页面完全没有译文 | 该页被判定为不适合翻译、或站点规则为 `never` | 打开弹窗看状态；检查站点规则 |
| 部分段落没翻译 | 超过「单页最多文本块」、懒加载未滚动到、文本被判为代码 | 调大上限、滚动页面、检查该段是否在 `<code>` 中 |

排查日志：在扩展页面按 `F12`，扩展输出的日志前缀为 `[ABT]`。
